## Special groups

Here is a list of the flags in glftpd that are supported in drftpd. The flagname in lower case is used as group name in DrFTPD

```
Flagname       	Description
-----------------------------------------------------
* siteop	User is siteop.
* gadmin	User is Groupadmin of his/her first public group (doesn't work for private groups).
* deleted	User is deleted.
* nuke		User is allowed to use site NUKE.
* exempt  	User is allowed to bybass max login limit.
```

Special groups will no longer exist in the future (2.1+)
