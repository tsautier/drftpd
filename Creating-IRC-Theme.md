DrFTPD version 3 has a much easier way to modify IRC themes compared to earlier versions. All `.properties` files are now edited in per frontend theme files. You will find the default builtin theme file in the `conf/themes` folder and called `core.theme.default`. This file is autogenerated on build and contains all `.properties` files from the installed plugins.

You should never edit the `core.theme.default` file as all your changes will be delete on rebuild. If you wish to change any formatting please copy the keys you wish to alter to a file named `core.theme` in this directory and make your changes there, this will prevent alterations being overwritten on a rebuild. It is not necessary to copy any keys for which you do not wish to change the formatting.
